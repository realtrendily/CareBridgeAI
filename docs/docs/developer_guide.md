# CareBridgeAI Developer Guide

## Project Structure
- `prototype/`: Contains the AI module and main script
- `docs/`: User and developer documentation
- `requirements.txt`: Python dependencies

## Adding Features
1. Update `ai_module.py` with new health rules or algorithms.
2. Update `sample_data.json` with test patient data.
3. Test using `main.py` before committing changes.

## Collaboration
Use GitHub pull requests for review. Maintain clear commit messages and update documentation with every feature.
