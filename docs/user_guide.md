# CareBridgeAI User Guide

## Overview
CareBridgeAI provides actionable recommendations for caregivers managing long-distance care. Input patient data into the system, and the AI will generate helpful care instructions.

## Running the Prototype
1. Navigate to the `prototype` folder.
2. Run `main.py`.
3. Review the printed recommendations for caregiving actions.

## Future Development
