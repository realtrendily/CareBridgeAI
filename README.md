# CareBridgeAI

**CareBridgeAI** is an AI-powered platform designed to support long-distance family caregivers by providing real-time health insights, care coordination tools, and communication assistance. 

## Features
- AI-driven health monitoring and alerts
- Task coordination for family caregivers
- Emotional support insights
- Prototype for rapid testing and feedback
